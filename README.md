# Arknights-JP-ZH-Refined

由 **芽咩洛（yameroooo1111）** 維護的《明日方舟》Windows 日服簡體中文修復版。

本專案基於繁花掠影的 [ArknightsLocalizationToolkit](https://github.com/2845086683/ArknightsLocalizationToolkit) 二次開發，補修詞庫與外掛後分享給大家。保留原版啟動器的外觀與操作方式。不是遊戲官方工具，也不是原作者發布的新版本。

目前版本：**2.1.1**。資料基準：2026-10-28 更新後的日服 PC 客戶端；修復整理日期：2026-10-29。

## 下載與使用

從本專案 [Releases](https://github.com/yameroooo1111/Arknights-JP-ZH-Refined/releases) 下載 `Arknights-JP-ZH-Refined-v2.1.1-win-x64.zip`，完整解壓後執行 `ArknightsRefined.exe`。

1. 選擇日服安裝目錄中的 `Arknights.exe`，區服選擇 `JP`。
2. 點擊導入詞庫旁的刷新，選擇隨包的「Refined 日服中文」詞庫。
3. 正常退出遊戲，按「安裝 / 修復並啟動」。程式會先校驗檔案並備份衝突檔案。
4. 安裝完成後，原本的遊戲啟動方式仍可使用。遊戲更新覆蓋外掛時，可重新執行安裝 / 修復。

Windows 10/11 64 位元；需要已下載完整資源的日服 PC 客戶端。一般安裝不需要另裝 Python、Conda 或申請翻譯 API Key。翻譯查詢在本機完成；初次啟動的框架相依元件可能仍需下載。

請保留整個解壓資料夾，不能只拿走 EXE。第一次產生執行環境可能需要一些時間。需要還原時，正常退出遊戲後使用「卸載漢化」。

注意，新版詞庫需搭配新版啟動器做使用。

## 為什麼建立這個版本

原版當時尚未更新到我使用時需要的內容，因此我在原作者的基礎上自行補修，順便分享給有相同需求的玩家。

本版本沿用國服的簡體中文與遊戲術語，沒有將遊戲整套改成繁體中文。新增修復以日服為主；程式保留原本的 EN 選項供匯入詞庫，但本包不附美服詞庫，也未對美服進行同等實機驗證。

## 這個版本改了什麼

| 範圍 | 修改內容 |
| --- | --- |
| 幹員語音與檔案 | 修正語音版本配對、方言／不同語音變體對應遺失、長篇檔案被略過，以及同一句日文在不同角色下對應不同中文的問題。起始修復案例為黍、可露希爾、凱爾希異格；同類查詢邏輯一併修正。 |
| 模組特性 | 修復角色養成頁與編隊頁翻譯不同步。補接養成頁實際使用的特性文字欄位，處理「基礎特性＋模組效果」的多行拼接、格式與數值。 |
| 吟遊者 | 補齊吟遊者分支描述，以及濁心斯卡蒂等角色裝備模組後產生的特性組合。 |
| 酒神、司霆驚蟄 | 修復酒神 RIT X 與司霆驚蟄 LIB X 在養成頁仍顯示日文的特性。 |
| 商城時裝 | 補齊時裝名稱、說明及相關介面文字的對應。 |
| 禮包 | 補齊禮包名稱與內容物名稱，處理項目前的圓點與附加數量；保留日服實際數量。 |
| 集成戰略 | 補齊部分藏品名稱、效果、用途、取得方式及解鎖說明。 |
| 生息演算 | 補正資料格式漏讀新版區塊的問題，加入戰術傾向、效果、解鎖條件、任務、地形、關卡說明、食物效果及載入提示；補齊基地升級文字、四個設施圖片標題的中文顯示，以及附帶進度的成就條件。 |
| 過場載入提示 | 補上關卡載入時顯示的遊戲提示文字，包括生息演算招集後固定技能、模組與等級的提示。 |
| 尋訪詳情 | 翻譯日服提供的幹員名單與完整規則，保留當期名單順序、機率、保底次數與重置條件，不以國服卡池替換日服卡池。 |
| 蝕刻章 | 補齊名稱、描述與取得條件查詢，處理條件前的短橫線及橘色進度；新增「取得指定 N 枚勳章」動態條件，包含回報的 6 枚、11 枚案例。 |
| 劇情 | 依劇情檔案查詞，處理同句不同譯、說話者、選項、累積顯示文字與玩家名稱；排除製作註解被當作台詞的情況。 |
| 顯示格式 | 恢復可確定對應的高亮、數值與富文本格式，處理譯文內的遊戲樣式標記，避免直接顯示 `<@lv.sand2desc>` 等內容。 |
| 其他文字 | 補齊活動、家具、任務、商店與動態數字提示。對於無法確定的完整句子，保留原文，避免不完整替換造成意思錯誤。 |

修復並不限於表中角色，同類型的文字對應與顯示邏輯也一併處理。

完整文字字典目前有 **514,188 條唯一來源文字**，另有依角色、劇情及介面查詢的資料。此數量包含標點、空白與顯示格式變體，不能當成新增原創譯文數量。

回報時請提供畫面、所在功能、幹員／模組／關卡名稱，以及遊戲與工具版本。請避免公開完整遊戲記錄、帳號資訊或個人備份；本工具不會自動上傳這些資料。

## 更新方式

「更新與設定」會檢查 **yameroooo1111/Arknights-JP-ZH-Refined**，不會把本修復版換回原作者版本。軟體與完整詞庫一起隨本專案 Release 更新；若倉庫另外提供詞庫資料，則可使用固定提交逐檔校驗並更新詞庫。只上傳 Release 而未提供獨立詞庫資料時，會略過獨立詞庫檢查。使用者自行匯入的詞庫會保留原有的來源設定。

設定儲存在 `%LOCALAPPDATA%/ArknightsJPZHRefined/launcher.json`，不會覆蓋原工具的設定。遊戲內已安裝的中文化由同一套安裝清單追蹤，切換工具前請正常退出遊戲。
